# Java - Estruturas de Decisão

## 📖 Objetivo

Este repositório reúne exercícios acadêmicos desenvolvidos em Java com foco na utilização de estruturas de decisão para resolução de problemas computacionais.

## 📂 Conteúdo

O repositório contém exercícios sobre:

- Estruturas condicionais (`if`, `else` e `else if`);
- Estrutura de seleção (`switch`);
- Operadores relacionais e lógicos;
- Desenvolvimento da lógica de programação;
- Entrada e saída de dados.

## 💻 Tecnologias

- Java
- Eclipse IDE

## ▶️ Como executar

1. Instale o Java JDK em seu computador.
2. Clone este repositório ou faça o download dos arquivos.
3. Abra o projeto no Eclipse IDE.
4. Execute a classe Java desejada.
